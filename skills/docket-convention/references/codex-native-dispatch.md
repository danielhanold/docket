# Codex native dispatch

Use the top-level native named-agent control for every registered Docket role. Treat launch and worktree markers as role metadata. Retain the returned child identity and observe that same child until terminal return; a notification or success sentence is not a gate verdict. Forward the immutable assignment and dispatch context unchanged, while retaining parent capabilities and the outer gate key in controller-private storage.

Resolve the candidate executable, catalog, and `schema --operation agent.check-inputs`. Pin a provisional assignment with `root_identity` omitted. For a resolver, pin a provisional resolver payload to that digest with the owned attempt and reservation. Run `agent.check-inputs` at `prepare`; the resolver path proves the exact conflict workspace before returning its root witness. Add the witness to the final assignment and freeze/hash its bytes. Pin the final resolver payload to that digest and rerun `agent.check-inputs` at `prepare`; other roles rerun with the final assignment alone. After success, prepare the child scope when applicable and construct private payloads. Each child verifies the absolute executable commit. If the role, native control, model, or catalog operation is unavailable, stop with a configuration diagnostic. Do not use `agent.enter`, shell runners, other harnesses, or generic agents.

Bind catalog argv[0] to the verified absolute candidate executable, not bare `docket`. Copy the final preparation's successful `entry_argv` unchanged into the payload: pinned executable and `--json`, no `--repo-dir` or payload flags. Those flags belong only to the outer invocation. Validate the final payload at `dispatch` before native dispatch; never reuse the provisional assignment's command.

On preparation, dispatch-validation or child failure, the controller records the concrete failure through catalog/schema-resolved `change.halt` with fresh version and verifies the durable halt before returning. Report halt-write refusals honestly. The parent obeys its keyed verdict; a halt does not confirm cancellation. Preserve the original epoch/native identity for explicit cancellation and supported resume.
