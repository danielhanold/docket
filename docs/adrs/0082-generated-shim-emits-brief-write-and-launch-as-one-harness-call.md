## Context

Docket generates a delegation shim (`sync-agents.sh`'s `emit_shim`) that instructs a model how to
hand a delegated child its task. Change 0271 established that the child's task text is its **only**
input — it inherits no conversation and no plan — and that omitting it fails silently into
improvisation. Change 0277 then moved that text off shell argv onto a file (`--brief-file`), because
argv forced a lossy, unverified, model-performed quoting step and the adapters flattened multi-line
briefs with `$*`.

The first implementation of the new shim taught a two-step recipe: call 1 writes the brief with
`mktemp` plus a quoted heredoc, call 2 launches with `--brief-file <the path you just wrote>`.
Whole-branch review caught that this cannot work. Harness Bash calls do not share shell state, and
`mktemp` produces a random suffix, so after call 1 the model has never seen the path: `$BRIEF` is
unset in call 2's fresh shell and expands empty, so the facade dies — or the model invents a
plausible path and dies differently. It would have failed on the sole taught channel, for every
runner and every delegated agent. No test caught it, because the shim sentinels asserted the
**slot's shape** and never that the recipe yields a usable path.

## Decision

A generated shim's **brief write and its launch are emitted as ONE harness call**, with the launch
referencing the live shell variable (`--brief-file "$BRIEF"`) rather than a placeholder the model
substitutes. The brief path stops being a model-carried value at all.

The general rule, for any future shim editor: **any value a generated instruction produces in one
harness call and consumes in another must be carried by a mechanism that survives the call
boundary** — the same shell invocation, or an explicitly printed value the instruction tells the
model to read and paste back. Never an unexported shell variable, and never an implicit "the path
you just wrote."

The testing corollary this cost us: **a sentinel over a generated instruction must pin that the
recipe EXECUTES to a usable value, not merely that a slot has the right shape.** A shape assert is
satisfied by a recipe that cannot run.

## Consequences

- Fewer model-performed steps on the child's only input. The brief path is no longer a slot, which
  removes an entire omission class from the shim.
- The shim's STEP 1 grows into one longer block — a readability cost accepted for the correctness.
- The rule constrains every future shim edit: a two-call recipe over a generated value is now a
  defect by construction, not a judgement call.
- The harness loads agent definitions at **process start**, so no shim change can be validated by
  the session that made it. The honest deliverable is evidence over the generator plus a read of the
  generated bytes; a live fresh-session dispatch remains a human verification item.
