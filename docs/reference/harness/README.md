# Harness validation

Reference material for validating docket on a specific harness (the tool that runs the agent:
Claude Code, Cursor, Codex, or opencode). For how to install, configure, and tune docket on your
harness, start at [Install and configure](../../install/README.md) and its per-harness pages; this
directory holds the exact procedure those pages point to when a live check is needed.

- [`validation.md`](validation.md) — the Cursor validation checklist: the best-effort `cursor-agent`
  CLI probe and the human-executed IDE checklist that must pass before a Cursor wrapper change
  merges.
