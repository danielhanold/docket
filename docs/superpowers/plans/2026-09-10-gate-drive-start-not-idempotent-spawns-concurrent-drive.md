# Worktree-Wide Gate Admission and Explicit Stop/Resume Ownership — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One canonical worktree carries at most one reserved-or-running top-level Docket gate execution across scopes, scopeless starts, raw launches, and automatic relaunches; human Stop becomes an explicit, cataloged `run.cancel` that durably fences a run epoch and is confirmed only after owned tasks, processes and admitted mutations are accounted for; resume admits exactly one replacement after verified shutdown.

**Architecture:** A new durable **worktree execution slot** (`internal/gatedrive/admission.go`, stored beside the existing drive/scope/budget roots under the git common dir) is reserved before every gate process launch — scoped starts compose it with 0405's `reserveScopeDrive`, scopeless starts are restructured to reserve-before-launch, `driveSlice`'s relaunch reserves the one permitted replacement before calling the backend, and raw `app.GateLaunch` inside a registered worktree acquires the same slot. A **reservation token** threaded through `process.LaunchRequest` into the pre-spawn manifest makes a lost launch response resolvable to its exact run. A **run epoch** record bound to the existing run-gate record/claim binding (`internal/app/rungate_epoch.go`) fences the coordinator: the new `run.cancel` operation flips active→cancelling under authority, stops registered native tasks and owned raw runs, journals mutation admission at the shared boundaries (transaction engine, PR publish, workspace publish), and reports cancelled only on full accounting. `run.gate-before --resume` and implement-next resume share that admission: refuse a live epoch, resume cleanup on a cancelling/unresolved one, and atomically supersede + reserve one replacement dispatch after confirmed cancellation.

**Tech Stack:** Go (`internal/gatedrive`, `internal/process` [stdlib-only], `internal/app`, `internal/cli`, `internal/codexentry`, `internal/repoguard`), cobra CLI, flock+atomic-rename persistence, the repo's own suite runner via `build.test_command`, markdown caller contracts under `skills/` + `cursor-rules/` with embedded mirrors regenerated by `go generate ./internal/assets/`.

**Spec:** `docs/superpowers/specs/2026-09-10-gate-drive-start-not-idempotent-spawns-concurrent-drive-design.md` (synchronized copy read from `.docket/`; the spec travels with this plan — executors read both). Change file: `docs/changes/active/0375-gate-drive-start-not-idempotent-spawns-concurrent-drive.md` on the `docket` branch.

## Global Constraints

- Design baseline: main `0f84b9e312b6cbb96973c0a30af3ce774ed079fa`. Change 0405's scope reservation/acknowledgement model, ADR-0117, and all its tests are preserved unchanged in behavior; change 0376's JSON capture/redaction boundary is preserved; changes 0412 (foreground/yield) and 0422 (outer retry epochs) are out of scope.
- Duplicate-start behavior is **refusal** with a safe locator (drive id + non-secret state) — never get-or-create, never credential recovery, never a fabricated success document, zero launches, and never stopping the incumbent.
- Fail closed everywhere: unknown schema, corrupt record, failed probe, inaccessible identity, mismatched registration, or a partially committed transition never means the worktree is free. A free flock, an old timestamp, quiet logs, a process-name match, or a lost RPC response is not proof a writer stopped. `probeUnknown` is never absence (per `internal/process` house invariant). Cleanup code must distinguish probe-error from clean absence — never fold an error return into the "not there" branch.
- Canonical identity only: worktree keys derive from `gitcli` canonical (every-symlink-hop-resolved) roots; a different run root, command, scope, owner, task, phase, or path spelling cannot buy a second slot. Tests must exercise the two-names-one-file case (`/tmp` → `/private/tmp` on macOS does this for free).
- Lock/authority order: **worktree admission → scope → drive**; run-epoch transitions use the worktree authority as their outer serialization boundary; no path acquires the outer authority while holding an inner scope/drive lock; no lock is held across a 30-second observation slice or a network call — use durable reservations and revalidate generations after returning. The slot outlives the CLI process: a flock is a critical-section primitive here, never the lifetime guarantee.
- Signalling: only exact owned identities through the existing `process.Stop` ownership conjunction; never broad `pkill`, time-based takeover, or deleting a lock file. `internal/process` production code stays stdlib-only (`TestImportBoundaryStdlibOnly`); diagnostics never include credentials, argv, env, or child output (`no_leak_test.go` discipline extends to every new record and reason).
- Accounting: admission precedes charging — a worktree-busy/unresolved/stale-epoch refusal reserves no full-suite attempt; once an admissible start has reserved an attempt, ADR-0116's no-refund rule holds for later launch/persistence failure. Relaunch, observation, cancellation and continuation never reserve a new attempt. No epoch dimension is added to the change-owned suite budget.
- Stable reason vocabulary added on the owning schema surface and mapped consistently through app/CLI/human output: `worktree-busy`, `unresolved-execution`, `run-cancelled`, `cancellation-pending`, `stale-run-epoch`, `owner-lifecycle-unavailable`. The WAITING/PASSED/FAILED/HALTED outcome vocabulary is NOT widened; cancellation is never a test failure or retry permission.
- Every changed durable schema is versioned; old/unknown records fail closed and cannot silently become free slots or live epochs; legacy drive records are inventoried on first use of the new registry (Task 6); no old credential migrates into a fresh owner.
- Every guard and load-bearing predicate gets mutation evidence: disable the guarded behavior, watch the specific assert redden for the intended reason, restore from a saved copy (never `git checkout --` over uncommitted work), defeat the test cache with `-count=1`. When the guarded thing is a loop's own exit condition, give the stub an independent hard stop so the mutation reddens instead of hanging.
- Concurrency tests are barrier-controlled (`racingProc`/`barrierGit` patterns, `sync.WaitGroup` tripped inside seam closures) and `-race`-clean; no arbitrary sleeps; count **backend `Launch` calls**, not surviving processes or final `RelaunchCount`. Every negative test has independent cleanup and a deadline. Real-process tests root at `testsupport.TempDir(t)` and quiesce via `testsupport.WaitQuiesced`.
- Whole-suite gate: the controller runs whatever `build.test_command` resolves to (at baseline `go run ./cmd/docket development test`), from source. Read the budget report even on green; `internal/gatedrive` and `internal/process` gain many tests — serial-confirm any wall-clock breach before acting.
- Comments/cross-references anchor on symbol names or verbatim-quoted clauses, never line numbers (`TestCommentAnchorStyle`).
- Maintained caller contracts and embedded mirrors update together; affected sites derived by repository search, never a fixed allowlist. After editing `skills/**` or `cursor-rules/**`, run `go generate ./internal/assets/` and refresh harness goldens.
- Workers: stage by explicit path only (never `add -A`); one commit per task on branch `fix/gate-drive-start-not-idempotent-spawns-concurrent-drive`; never touch `.docket/`, the metadata branch, or the board.

```go
const admissionSchemaVersion = 1

type admissionState string
const (
    admissionReserved   admissionState = "reserved"
    admissionExecuting  admissionState = "executing"
    admissionStopping   admissionState = "stopping"
    admissionUnresolved admissionState = "unresolved"
    admissionReleased   admissionState = "released"
)

type admissionRecord struct {
    SchemaVersion int
    RepoIdentity  string // canonical git common dir
    WorktreeRoot  string // canonical worktree root (or "" for a raw non-worktree root — Task 7 never stores those)
    State         admissionState
    ExecutionGen  int    // logical execution counter, monotonic per worktree
    ReservationToken string // random token; also handed to process.Launch (Task 2)
    DriveID       string // "" for raw launches
    ScopeID       string // "" when scopeless/raw
    RunEpochID    string // "" for standalone gates (Task 9 links workflow gates)
    RawRunID, RawRunDir string // attached at confirm
    Kind          string // "scoped"|"scopeless"|"raw"
    ReservedAt, UpdatedAt time.Time
}
type storedAdmission struct { Generation string; Record admissionRecord }

func admissionKey(worktreeRoot string) string // sha256 hex of the canonical root — passes validateID
func (s *Store) ReserveWorktreeExecution(rec admissionRecord) (token string, err error)
func (s *Store) ConfirmWorktreeExecution(worktreeRoot, token, rawRunID, rawRunDir string) error
func (s *Store) ReleaseWorktreeExecution(worktreeRoot, token string) error       // caller supplies teardown proof (Task 6 gates it)
func (s *Store) MarkWorktreeExecutionUnresolved(worktreeRoot, token string) error
func (s *Store) MarkWorktreeExecutionStopping(worktreeRoot, token string) error  // used by run.cancel (Task 10)
func (s *Store) LoadWorktreeExecution(worktreeRoot string) (admissionRecord, string, error) // record, generation
func (s *Store) admissionCAS(worktreeRoot string, mutate func(*admissionRecord) error) error
```

Semantics to implement exactly: `ReserveWorktreeExecution` refuses (typed `ErrWorktreeBusy` for reserved/executing/stopping, `ErrUnresolvedExecution` for unresolved) whenever the current record is not `released`/absent; on success it bumps `ExecutionGen`, mints `ReservationToken` via `randomToken(genNBytes)`, persists `reserved`. A `released` record is overwritten in place (its facts survive in the pre-mutation copy read under the CAS — releasing preserves `DriveID`/`RawRunID` so the record is historical evidence, per spec "Released records remain historical evidence"). Unknown `SchemaVersion` or corrupt JSON → `ErrUnknownSchema`/`ErrCorruptRecord`, never a free slot. All transitions verify `ReservationToken` equality (a stale caller cannot release the successor's slot). Reuse `writeAtomicJSON`, `acquireExclusiveLock`, `ensurePrivateDir`, `validateID` — the store's existing primitives, same 0700/0600 modes.
