# Unquote Cursor Agent Wrapper Names Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use docket-build (this change's resolved build skill) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Emit the `name:` field of generated Cursor custom-agent wrappers as a bare YAML scalar (`name: docket-implement-next`), because Cursor registers the Task `subagent_type` enum value verbatim — quotes included — and rejects dispatch of the unquoted name.

**Architecture:** One-line renderer change in `internal/harness/cursor/cursor.go` `renderAgent`: stop routing `s.Name` through `quoteYAML` and emit it bare. `description:` stays quoted via `quoteYAML` (ADR-0071 free-text rule). Safety is not hand-enumerated: the existing `verifyRoundTrip` reparse already refuses any rendered document whose `name:` does not read back as the source value — the same mechanism that makes the bare `model:` line safe — so a name that would not survive bare serialization fails at render time rather than shipping (learnings: `validator-must-match-the-reader-it-feeds` — lean on the reader's own reparse, never a hand-listed accept set). The 17 frozen agent goldens under `internal/harness/cursor/testdata/golden/` are regenerated via the suite's own `-update` flag, and the one executable guard asserting the quoted form (`cursor_test.go`, the `HasPrefix(content, "---\nname: '"+name+"'\n")` assert) flips to expect the bare form.

**Tech Stack:** Go (stdlib + repo-internal packages only); `go test` with the package's existing `-update` golden-regeneration flag.

**Spec:** none — trivial change; the authority is the change file `docs/changes/active/0356-unquote-cursor-agent-wrapper-names.md` on the `docket` metadata branch (its "What changes" section is the scope).

The first assert is written to DETECT the state being removed: against the current renderer the content opens `---\nname: 'docket-…` and the bare-prefix match fails. The second assert pins the out-of-scope boundary so a build cannot "fix" the name by unquoting everything (learnings: `fix-reintroduces-its-own-defect-class`, `assert-detects-removal-not-replacement`).
