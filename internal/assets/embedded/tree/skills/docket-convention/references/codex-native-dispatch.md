# Codex native dispatch

Use the top-level native named-agent control for every registered Docket role. Treat launch and worktree markers as role metadata. Retain the returned child identity and observe that same child until terminal return; a notification or success sentence is not a gate verdict. Forward the immutable assignment and dispatch context unchanged, while retaining parent capabilities and the outer gate key in controller-private storage.

Resolve the candidate Docket executable, its capability catalog, and `schema --operation agent.check-inputs` before work. Construct the schema-described assignment only after controller-owned preparation returns the root witness; prepare any child scope next, then construct and dispatch the separate private payload envelope. Each child verifies the same absolute executable commit independently. If the registered role, native dispatch control, required model, or catalog operation is unavailable, stop with a configuration diagnostic. Do not route through `agent.enter`, a shell runner, another harness, or a generic agent.

For every candidate operation, bind catalog argv[0] to the verified absolute candidate executable; the catalog's generic `docket` spelling is not a runtime selection. After incorporating the root witness, freeze and hash the final assignment and run `agent.check-inputs` at `prepare` for those exact bytes. Copy its successful `entry_argv` result unchanged into the payload. It contains the pinned absolute executable and `--json`, with no `--repo-dir` or payload flags. Repository and payload locator/digest flags belong only to the outer checker invocation. Validate the final payload at `dispatch` before native dispatch; do not construct the pinned command from the catalog's optional flags or reuse a command for an earlier assignment digest.

If preparation, dispatch validation, or the child fails before a valid sub-step receipt, the controller records the concrete failure through catalog/schema-resolved `change.halt` with fresh change version and verifies the durable halt before returning. A halt-write refusal must be reported as such, never called a recorded halt. The parent still obeys its keyed gate verdict; neither diagnostic prose nor a durable halt confirms epoch cancellation. Preserve the original epoch and native identity for explicit cancellation and supported resume.
